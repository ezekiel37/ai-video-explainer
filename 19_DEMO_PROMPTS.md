# Demo Prompts

## Demo 1 — Money transfer

```text
Explain how a user sends money from User A to User B in a fintech app. Show the user entering the amount, the mobile app sending a request to the backend, authentication checks, fraud checks, ledger debit, ledger credit, notification to both users, and final success state.
```

## Demo 2 — SaaS onboarding

```text
Explain how a new user gets onboarded into a SaaS product. Show signup, email verification, profile setup, preference selection, checklist completion, and arrival at the dashboard.
```

## Demo 3 — API request lifecycle

```text
Explain what happens when a frontend app sends an API request. Show the browser, API gateway, authentication service, business logic service, database, response back to browser, and error handling path.
```

## Post-MVP Demo — Photography lighting

```text
Explain a simple three-point lighting setup for portrait photography. Show the subject, key light, fill light, back light, camera, and how each light changes the final image.
```

## Demo 4 — Delivery workflow

```text
Explain how an online order moves from checkout to delivery. Show customer checkout, payment confirmation, warehouse picking, dispatch assignment, rider pickup, route tracking, and successful delivery.
```
